# Skills

A collection of reusable skills.

## Content Story Architect

[Content Story Architect](content-story-architect/SKILL.md) develops content ideas, hooks, scripts, and revisions using bundled storytelling frameworks and progression mechanics. Includes reference guides, workspace setup and framework validation scripts, and agent configuration.

## Taste Board

[Taste Board](taste-board/README.md) maintains a local library of design references, renders moodboards, and turns collected references into reusable design rules.

Imported from [mauricehendricks/taste-board](https://github.com/mauricehendricks/taste-board) at commit `8ddf2958cb5006e8f753c68bfec59e4317667ab6`. Its MIT license is preserved in [taste-board/LICENSE](taste-board/LICENSE).
