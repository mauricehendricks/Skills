# Skills

A growing collection of reusable agent skills for a wide range of tasks and workflows. Each skill lives in its own directory with a `SKILL.md` entry point and any supporting references, scripts, or assets.

## Available skills

| Skill | Purpose |
| --- | --- |
| [Content Story Architect](content-story-architect/SKILL.md) | Develop content ideas, hooks, scripts, and revisions using storytelling frameworks and progression mechanics. |
| [Taste Board](taste-board/README.md) | Maintain a local library of design references, render moodboards, and turn collected references into reusable design rules. |

## Using a skill

Open a skill's directory for its instructions and supporting documentation. To install manually, copy that directory into the skills directory supported by your agent.
